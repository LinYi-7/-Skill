# 封面与排版

## 观察与设计决策分开

正文视觉实看：功能教程同步页有白底、深色文字、粗体问题标题、手机操作图；社交观察同步页有绿色强调、原创插画、聊天气泡和模块编号。腾讯新闻会重排正文，因此不能从这些页面推出微信内字号、边距、完整交互行为。

列表缩略图实看：界面截图、绿底单一表情物、实景照片并存。这里只能确认腾讯新闻列表的缩略图；未核验它们是否等于原公众号封面。绿色并非所有题材的唯一选项。

以下像素、颜色、比例均为本工具的制作默认，不是微信派的精确设计参数或平台最新强制规格。

## 原创封面规格

| 方案 | 适合材料 | 设计方法 |
|---|---|---|
| 单物体隐喻 | 一项清楚变化 | 单色背景+一个主体+少量字；主体的形状或动作体现变化 |
| 界面证据 | 操作教程、入口变化 | 真实界面局部放大+一个重点标记；删除无关信息，敏感信息打码 |
| 情景插画 | 社交观察、情绪共鸣 | 一个熟悉场景+2–3个角色或气泡；不要把所有正文搬进封面 |
| 真实物件/现场 | 品牌故事、纪念、活动 | 一张有意义的真实照片+短句；不伪造历史照片或用户故事 |

交付宽版900×383与方版600×600，或按用户指定规格。宽版中央约383×383区域作为方形裁切的构图参考；主要物体与关键字留在安全区，仍单独导出方版并目视检查。不要宣称这是平台唯一尺寸。

封面文字默认0–8个汉字（可调整），标题负责明确承诺，封面负责提供视觉线索和情绪。缩小到约180px宽后检查主体和文字；不要只在放大图上判断。

优先用户品牌色；未知品牌用白底、深灰、一个绿色点缀的中性方案。可用#168A50作深绿色强调、#F0F7F2作浅背景；这不是官方品牌色。不得放微信派Logo、官方认证或“微信官方”署名。

# 基本要求
1. 为【品牌/主题】制作原创公众号封面，表达【已证实的核心变化】，视觉采用【具体构图】。
2. 如果输入原文主要是什么语言，则输出遵循同样的语言；本次图片文字按用户指定语言。
3. 主体【物体/场景】，背景【颜色】，留白【位置】，避免加入材料未提供的功能、数据或标志。
# 输出要求
## 宽版与方版
**画面**
【尺寸、主体位置、裁切安全区和颜色】
**文案**
【准确短文案；若图内文字不稳，留空并后期排字】

## 正文默认排版

正文16px、行高1.8、左右留白约20px、段后14px；小标题20px粗体、段前28px；注释13px且保证可读对比度。移动端以约375–430px宽检查。这些参数可随品牌和读者调整。

正文左对齐；短导语或独立标语才可居中。单段尽量1–3句话，不为了“短”拆成每行两三个字。每节最多突出1–2个重点，避免整段全绿、全粗或过量表情符号。图片下紧跟用途或步骤图注。

HTML保持内联样式和简单section/p/img/h2，不插入脚本、表单、追踪像素。对滑动或SVG交互，输出完整静态顺序图作为基础版；未经目标编辑器和手机预览，不声称交互可直接发布。

## 排版生成器输入

`python3 scripts/render_article.py article.json article.html`

JSON结构：

```json
{
  "title": "成稿标题",
  "subtitle": "摘要（可省略）",
  "blocks": [
    {"type": "p", "text": "完整自然段"},
    {"type": "h2", "text": "读者问题"},
    {"type": "p", "text": "答案"},
    {"type": "image", "src": "assets/step-1.png", "alt": "操作步骤一", "caption": "图注"},
    {"type": "note", "text": "适用条件"}
  ]
}
```

支持p/h2/note/image。没有图片时不伪造路径；省略image块并在审核说明列出缺图。生成器转义所有文本，拒绝脚本URL；它只负责排版，不证明文稿事实正确。图像本地相对路径以HTML所在目录解析；实际在公众号使用需上传图片并预览。最终文件保存遵循当前环境交付规则。
