# 阅读表现复盘

## 输入及证据

接受用户合法获取的后台导出或可信观测表。其他公众号的后台数据通常不由用户掌握；可提供公开阅读数或有权使用的数据服务导出，不索取登录密码、Cookie或会话令牌。全量分析先核对历史目录及起止时间，不把搜索命中集合叫“所有推文”。

最少需要：文章唯一标识、标题、原文链接或正文材料、发布时间、阅读数、平台、账号、阅读指标口径（PV/UV）、统计窗口、观测时间、数据来源。缺正文仅能做标题层面的假设；缺封面不评价封面实物；阅读缺失不能计0。

如果使用CSV，字段对应以下JSON字段；数字中的逗号需正确引用。优先JSON以减少表格歧义。后台字段名随版本不同，必须按实际导出定义映射，不臆造不存在的后台维度。

```json
[
  {
    "article_id": "业务唯一标识",
    "title": "文章标题",
    "url": "真实文章链接",
    "published_at": "2026-08-01T10:00:00+08:00",
    "observed_at": "2026-08-04T10:00:00+08:00",
    "platform": "微信公众号",
    "account": "目标公众号",
    "metric": "read_uv",
    "window_hours": "72",
    "cohort": "2026-08头条同主题",
    "reads": "100000+",
    "data_source": "用户提供的观测表"
  }
]
```

脚本：`python3 scripts/rank_articles.py records.json ranked.json`（也接受.csv）。脚本不抓取或登录网站，不对缺失数据补值。它按账号、平台、指标、窗口和cohort分组，对精确值降序排名；并列采用竞赛排名。截断值和未知值单独列出。cohort由实际数据确定，不为制造显著性随意切组。

`100000+`或`10万+`表示下界，不能当100000精确排序，更不能据此区分两个10万+文章。真实0必须为0，空值、“未知”、NA均为缺失。腾讯新闻的“听过”“评论”“点赞”不是原微信公众号阅读量。

累计值可作为累计表现单独排序，但文章发布越早有越多积累时间，因此不能直接据累计排名比较内容质量。增长复盘优先固定24小时、72小时、7天窗口；缺窗口的记录会被隔离，不能给出高低内容结论。

## 解释阅读量，不倒推原因

总阅读可能来自粉丝送达、推荐、搜索、分享、外部导流和付费流量。微信派的官方身份、平台级用户基础和首发信息优势都可能影响结果；本技能无法控制这些条件，也不能承诺其他品牌复制相同流量。

先按同账号、近日期、同头条位置、相近主题、相同窗口、相同口径比较。至少检查发布时间、发文位置、推广活动、受众宽窄、时效性；取不到时列为未知混杂项。

高/低样本优先选组内上/下四分位，组内不足8篇只作描述，不给稳定规律标签。每篇用同一提纲：

## 【排名或截断组】文章标题
**数据事实**
数值/下界、口径、窗口、观测时间、来源、比较组。
**标题与封面**
观察到什么；封面是否可见、是否原封面。
**正文与排版**
首屏兑现、信息密度、证据、模块和行动。
**可能受欢迎/流失的机制**
至少一个可证伪假设，明确是推断。
**替代解释**
触达、话题热度、官方首发、推广、时长积累或人群窄；未知就写未知。
**具体改法**
一条新标题、一个封面调整、一个开头或结构改法，保持事实一致。
**验证**
改一个变量，看一个主指标和一个辅助指标。

全部有效记录逐篇输出，不能只挑爆款讲故事；缺正文/视觉材料的记录标为对应层面未评，不拿标题脑补全文。

## 诊断漏斗

| 观测现象 | 可检查假设 | 优先改动 | 需要的证据 |
|---|---|---|---|
| 阅读低，打开率正常 | 送达或受众规模低 | 分发与选题覆盖 | 相同来源的送达和打开数据 |
| 送达相近，打开率低 | 标题封面不清楚或收益弱 | 标题或封面一次改一个 | 同窗口订阅来源打开UV/送达UV |
| 打开正常，读完低 | 标题过度承诺、开头慢、信息不匹配 | 前120字与模块顺序 | 同口径完读或可用停留数据 |
| 读完正常，分享低 | 缺可转给他人的具体价值 | 增加速查清单或明确场景 | 分享人数/阅读人数 |
| 阅读高，关注低 | 内容与账号未来价值关联弱 | 明确持续内容承诺 | 可归因新增关注/非关注读者UV |

分子分母必须同平台、同来源、同时间窗。没有非关注读者UV或归因数据时不要计算“关注转化率”；可报告原始新增关注并说明归因限制。不要把总阅读UV除送达UV命名为粉丝打开率。

## 验证策略

有合法随机分流能力时比较两版，预先固定结束时间、主指标与受众，避免边看边停；没有时做相近条件配对，明确是观察而非因果。不要规定一个通用样本量或用少数文章的相关性下定论。没有数据时给可执行实验，不输出伪排名、伪显著性或预测阅读量。
